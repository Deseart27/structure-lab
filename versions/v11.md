# V11 — Contacts & Enrichments Revamp

## Decisions (voted 30/07)

### 1. Optional lists
Lists are optional. When adding contacts or companies, they go to **All Contacts | All Companies**. Adding them to a list is optional.

### 2. We keep an Enrichment section populated with "Enrichment Jobs"
Enrichments are the heart of FullEnrich. This section displays Enrichment Jobs.
On click, redirects to Contacts/Lists section.
**TBD**: as a filter on All Contacts, or as a job contacts dedicated view (currently: dedicated view with banner + contact table).

### 3. Enrichment stats must stay at a core-value level
Stats shown to the user reflect business value:
- **Enrichment log**: found rate (198/234) + email/phone icon counts
- **Job detail**: donut charts — email (valid/risky/invalid/not found), phone (found/not found), credits
- **List stats**: enrichment coverage % + CTA to enrich remaining + email/phone counts

## Architecture

### Sidebar order (Contacts section)
1. **Enrichments** — default landing, pulsing badge when jobs running
2. **All Contacts** — every contact across all sources
3. **Lists** — optional grouping with "+" to create

### URL routing
- `/prospects` — Enrichments log (default)
- `/prospects?view=contacts` — All Contacts
- `/prospects?job={id}` — Job detail view
- `/prospects?view=contacts&enrichment={id}` — All Contacts filtered by enrichment
- `/prospects/{listId}` — List detail

### Core principle
> Contact is the persistent core object. Enrichment Job is an immutable receipt. List is a human-made optional lens.
