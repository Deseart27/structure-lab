# V9 — FullEnrich Product Redesign Summary

## Context

FullEnrich is a B2B data enrichment platform. Users find contacts (via search, CSV upload, reverse lookup, or CRM import), enrich them (find professional emails, direct phone numbers, or resolve email-to-profile), and push results to their CRM or export them.

V9 is a structural redesign of the application. It is built as an interactive prototype in SvelteKit with Tailwind CSS, hosted on GitHub Pages. The prototype covers navigation, contacts management, enrichment workflows, and search — all with mock data.

---

## Core Philosophy: Contact as the Core Object

### Before (V1-V8)
The **list** was the core object. Every enrichment auto-created a list. Users managed their data through lists. The mental model was: "I have lists of contacts."

### V9
The **contact** is the core object. Contacts exist independently and persist regardless of how they were created. Lists are intentional groupings that users create on purpose — they are organizational tools, not automatic byproducts of enrichment.

Key consequences of this shift:
- No auto-created lists. Every list is deliberately created by the user.
- An "All Contacts" view shows every contact across all sources.
- An "All Companies" view shows every company across all lists.
- Enrichment jobs are metadata/filters on contacts, not list-creation events.
- Deleting a list does NOT delete the contacts — they remain in All Contacts.
- When starting an enrichment from anywhere (search, enrichment page), adding to a list is optional (default: "No list").

## Navigation Structure

### Main Nav (top bar)
`Search` | `Enrichment` | `Contacts` | `Integrations`

"Contacts" replaced "Lists" to reflect the new mental model.

### Sub Nav
Only appears for Search (People | Companies) and Integrations (CRM | Engagement | API & MCP). The Enrichment and Contacts sections handle their own internal navigation.

## Contacts Section (`/app/prospects`)

### Layout
Three-column layout inside a rounded card container:
1. **Left sidebar** (w-56) — list navigation
2. **Main content** (flex-1) — contact/company table
3. **Right panel** (w-72) — enrichment runs

### Left Sidebar
- **Toggle**: "My lists" / "All lists" — filters lists by ownership
- **CONTACTS** section header (bold uppercase, grey-800)
  - "All Contacts" link (with total count)
  - People-type lists below (each with folder icon + contact count)
- **COMPANIES** section header (same style)
  - "All Companies" link (with total count)
  - Company-type lists below

No "Recent Enrichments" in the sidebar — that's in the right panel.

### All Contacts View (`/app/prospects`)
Header bar: "All Contacts" title + count | Add contact | Import | Export dropdown | Enrich (primary purple button)

Table columns: Checkbox | Name + location | Company | Title | Email (styled) | Phone (styled) | HubSpot icon | In lists (pill tags)

**Email styling**: Pink `email` icon + bold monospace text + green `check_circle` if valid. If no email: grey dash.

**Phone styling**: Purple `phone` icon + monospace text. If no phone: a discrete "Find phone" button (ghost style with phone icon).

**HubSpot icon**: Per-row button using the actual HubSpot sprocket SVG logo. Synced contacts: orange (#FF7A59), full opacity. Not synced: grey (#9CA3AF), 40% opacity, brightens on hover. Clicking shows a toast.

**Enrichment filter**: When `?enrichment=r1` is in the URL, a violet banner appears showing which enrichment is filtering the view, with "Clear" and "Save as list" actions. The right panel highlights the active enrichment run.

**Selection**: Checkboxes on each row. Header checkbox toggles all. Selected rows get a violet-50 tint. Enrich/Export buttons reflect selection count.

### List Detail View (`/app/prospects/[listId]`)
Same layout as All Contacts but scoped to a specific list.
Header: List name + type badge + contact count | Add contact | Export | Enrich
Table: Same columns as All Contacts minus "In lists" column, plus HubSpot icon.
Right panel: Enrichment runs filtered to this list.

### All Companies View (`/app/prospects/companies`)
Header: "All Companies" + count | Add company
Table: Company name + type | Domain | Industry | Headcount | Location | Founded | In lists

### Right Panel (Enrichment Runs)
Present on All Contacts and List Detail views. Header: "Enrichments" + running count.

Each enrichment run is a card with:
- Icon based on input method (description for CSV, search for search, hub for CRM, edit for manual)
- Run name (truncated)
- "found/total found" + timestamp
- Status indicator:
  - **Running**: spinning `sync` icon (1.5s animation) + shimmer gradient progress bar (violet-400 to violet-600) + percentage
  - **Completed**: green `check_circle`
  - **Queued**: grey `schedule`

Clicking a run navigates to `?enrichment={run.id}` which filters the contact table.

## Enrichment Section (`/app/enrich`)

### Layout
Same rounded card container as Contacts. Two-column layout:
1. **Main content** (flex-1, max-w-800px centered) — subsection selector + workflow
2. **Right panel** (w-72) — enrichment runs (identical UI to contacts right panel)

### Subsection Selector
Three horizontal cards at the top, each acting as a navigation trigger:

1. **Find Emails & Phones** (violet border/bg when active) — `contacts` icon
2. **Reverse Enrichment** (teal) — `swap_horiz` icon
3. **CRM Enrichment** (orange) — `hub` icon

Cards use `text-sm font-semibold` labels. No check icons. Active card gets colored border + light bg + shadow.

### Find Emails & Phones (default subsection)
- Title + description
- **What to find**: Radio buttons — "Emails only" | "Phones only" | "Both". Selected option gets violet border + bg.
- **Provide contacts**: 2x2 grid of input method cards:
  - Upload a CSV
  - Add manually
  - From a list
  - From my CRM
  Each card opens the enrichment modal at step 2.

### Reverse Enrichment
- Title + description
- **Provide emails**: 2-column grid:
  - Upload a CSV
  - Enter manually

### CRM Enrichment
- Title + description
- **Connected CRMs**: Card showing HubSpot as connected (sprocket logo, "2,847 contacts synced", green Active badge, "Enrich CRM contacts" primary button)
- "Connect another CRM" placeholder card (dashed border)

### Enrichment Modal (shared V8/V9)
Triggered by clicking an input method card. Two steps:
1. Step 1: Pick input method (only shown for non-reverse, non-specific clicks)
2. Step 2: Configure and launch

Includes a "Where should results go?" selector:
- V9: "No list" (default) — "contacts added to All Contacts"
- Existing lists as radio options
- "Create new list" option

## Data Model (Mock Store)

### Contact
```
id, firstName, lastName, company, title, email, emailStatus (valid|catch-all|invalid-found|not-found|pending), phone, personalEmail, linkedinUrl, location, hubspotSynced?
```

### V6List
```
id, type (people|company), name, memberIds[], sources[], owner, updatedAt, enrichedPercent, enrichmentStatus?
```
Only 3 intentional lists exist (no auto-created):
- Q3 Targets (people, 7 contacts)
- ABM - Fintech FR (company, 4 companies)
- Sales Leaders DACH (people, 4 contacts)

### EnrichmentRun
```
id, listId? (optional), listName?, name, outputType (emails|phones|reverse|all), inputMethod (csv|manual|crm|list|search), contactIds[], contactsCount, found, status (running|completed|queued), progress, startedAt
```
Runs can be standalone (no listId) — they exist as enrichment jobs on contacts, not on lists.

### Key relationships
- `getListsForContact(contactId)` — which lists contain this contact
- `getContactsForRun(run)` — which contacts were in this enrichment
- `getRunsForList(listId)` — enrichment history for a list
- Contacts persist independently of lists and runs

## Design System

- **Colors**: Violet (primary/brand), Pink (email icons), Blue (phone-related), Teal (reverse enrichment), Orange (CRM/HubSpot), Emerald (success/valid), Amber (running/warning), Grey (neutral)
- **Typography**: text-sm for body, text-xs for metadata, font-mono for emails/phones, uppercase tracking-wider for section headers
- **Components**: Rounded cards (rounded-2xl), pill badges, ghost buttons (btn-ghost), primary buttons (btn-primary, violet), table rows with hover states
- **Animations**: CSS @keyframes shimmer on progress bars, spinning sync icon for running enrichments

---

## What's Decided

- Contact is the core object, not the list
- No auto-created lists
- Enrichment runs are filters/metadata, accessible from a right panel
- "Add to list" is optional everywhere (default: no list)
- HubSpot sync status visible per contact row
- Three enrichment subsections: Find Emails & Phones, Reverse, CRM
- Sidebar: My lists / All lists toggle, Contacts + Companies sections
